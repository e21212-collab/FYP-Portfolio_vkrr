Project Overview

What Is This Project About?

This project builds a vibration-based artificial robotic antenna inspired by insect antennae (feelers). An accelerometer is mounted on the tip of a plastic tube to detect contacts through vibration. The antenna is mounted on a Pan-Tilt unit, which is attached to a mobile robot platform. .

When the robot moves (ego-motion), the antenna vibrates from the robot's own motion — making it impossible to distinguish genuine contact events from movement noise. This project develops a bio-inspired cancellation algorithm to remove ego-motion effects and restore clean contact detection.

Project Themes

Core Technical Areas of This Project

The project spans sensor physics, signal processing theory, and experimental validation — bridging the gap between theoretical noise models and practical cancellation techniques.

Full Methodology
Vibration Sensing

Understanding how mechanosensors transduce mechanical vibrations into electrical signals and where ego-motion introduces artefacts.

Adaptive Filtering

Using reference sensors and adaptive algorithms (LMS, RLS) to subtract ego-motion-induced signals in real time.

Ego-Motion Modelling

Mathematical modelling of self-generated motion and its spectral overlap with target stimulus frequencies.

Signal Validation

Quantitative evaluation of cancellation performance using SNR, coherence analysis, and real-world test scenarios.
